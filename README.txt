HOME BUDGET HK — iPhone Offline PWA

DEPLOY: Extract ZIP. Upload all five files (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) to the ROOT of a GitHub repository. GitHub repo > Settings > Pages > Deploy from a branch > main > /(root) > Save. Open the published HTTPS URL in Safari on iPhone, Share > Add to Home Screen. Open once online to cache files for offline use.

Includes mortgage estimate, renovation item list, independent person contribution comparison, monthly savings tracker, local auto-save, JSON export/import.

Privacy: no login, analytics, API or cloud database. Data remains in this browser's localStorage. Clearing Safari website data can erase it; export backups regularly. Initial visit and caching require internet. Mortgage figures are estimates only.
